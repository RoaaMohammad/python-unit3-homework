# Day 25 Feature Engineering - Main Version

This Python project applies feature engineering techniques to a dataset.

## Features
- Creates new features from existing columns.
- Applies mathematical transformations.
- Displays the engineered dataset.

## How to Run
1. Install pandas, numpy, and scikit-learn.
2. Place `day25_project.csv` inside the `data2` folder.
3. Run `day25_activity_skeleton.py` using PyCharm.
